# Optional appendix code

This directory is separate from the four main experiments. It contains only
supporting diagnostics that are useful for an appendix or a follow-up audit;
none of these files is required by the paper-facing RQ1--RQ4 runs.

The main RQ3 decomposition and ablation scripts live under
`experiments/rq3_sae/`. Keep generated hidden states, model weights, prompts,
and logs outside this release tree.
